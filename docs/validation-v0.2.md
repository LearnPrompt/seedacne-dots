## 已覆盖的关键行为

- 官方 OpenAI fileParams schema；PNG/JPEG/WebP 实际字节、格式、尺寸和 10 MiB 限制。
- 精确下载主机允许名单、HTTPS、重定向拒绝、下载不携带方舟凭据、签名 URL 不进入账本/错误。
- 上传防重、模糊失败不重发、跨用户参考图与任务访问隔离。
- 使用方舟挂载响应的文件 ID 构造图片内容块。
- 原 Session 续接、稳定 turn_id、并发不同轮拦截、运行中/待确认/终止 Session 拒绝新轮。
- 新轮终态、回复、错误和产物隔离；旧轮延迟注册文件不归入新轮。
- Files 的 after/has_more 分页；v0.1 根轮快照兼容。
- 12,000 字中文请求及 64 KiB UTF-8 请求上限。

真实墙钟 20 秒超时使用异常模拟，并非测试中等待 20 秒。真实上传初次被空下载来源名单拦截；核验并配置实际宿主域名后，复用原部署版本应用配置，上传成功。观察到不同区域下载 hostname，因此按每个实例的真实来源配置精确名单，不将任意域名放开。

本轮尚未启动新的图片/视频生成模型调用；原 Session 两轮修改的后续真实产物验收见下文，不能把上传成功或旧文件当作完成。
