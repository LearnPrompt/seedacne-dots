# 需要本人操作或授权的环节

这些检查点在实际遇到时触发，不是每次安装必须重复确认的清单。Codex 应先把对象准备到可核对的程度，再请求必要授权；其他独立工作继续推进。

| 环节 | 本人处理什么 | 确认前准备好什么 |
|---|---|---|
| 登录与验证 | 本人在官方页面输入密码、短信码、扫码或完成设备验证 | 正确账号与官方登录页；不要求把验证码发到聊天 |
| 服务协议 | 同意当前具体服务的条款并允许开通 | 服务/模型名称、协议、开通动作与当前计费说明 |
| 专用凭据 | 授权创建限定权限 Key，并安全存入指定私有服务 | Key 名称、准确权限、接收服务完整网址、仅服务端存储方式和用途 |
| 插件权限 | 确认新增的实质访问权限，必要时由管理员批准 | 连接账户、插件、访问范围；不能绕过管理员限制 |
| 充值或付款 | 本人付款，或给予明确商户、用途与限额授权 | 当前价格、金额及具体用途；配置请求不等于付款授权 |
| 首次付费生成 | 明确测试内容、调用范围与费用边界 | 视频/图片规格、只做几个任务、失败处理、是否具备费用硬上限 |

接受协议、新增敏感访问或转存凭据时，遵守执行平台的当次确认要求。用户已明确授权且对象、权限、接收位置、用途与费用范围未变时，不重复问同一问题；扩大范围应重新确认。

## 可复制回复

在 Codex 已展示具体对象后按需使用，不能代替对未知资源的审查。

**服务开通：**

> 我已阅读你列出的当前协议，同意为刚展示的服务、模型与 Agent 开通并创建。按当前页面计费说明执行，本次不提交素材生成。

**专用 Key 与私有服务：**

> 授权创建你刚展示的专用 Key，保持所列权限，安全写入你刚展示的、仅我可访问的私有服务的服务端秘密变量。允许 Dots 在我请求时调用；不改其他 Key，本次先只读验证。

**一次视频首测：**

> 授权通过我的专用插件提交一次约 5 秒、9:16、720P 的奶茶视频测试。只做这一项，不制作海报或其他版本。按刚说明的费用范围执行；结果不明时查原任务，未经确认不重新生成。

如需金额限制，应先填入自己接受的范围并确认平台能否执行。当前模板**没有金额硬上限**；一次 Managed Agent 任务可能调用多个模型和工具，不能将“一次任务”当成确定总价。无法满足用户的硬预算时，应在生成前说明并暂停依赖动作。

## 通常可以继续的准备工作

在用户已要求接入的范围内，文档核对、允许的只读资源检查、代码与草稿准备、本地测试，以及符合平台规则的私有部署，无需每一步请求确认。默认 `GENERATION_ENABLED=false`；完成只读验证不需要付费生成来证明。

发布本仓库及示例媒体的授权属于本项目，不能用于他人的账号、Key、素材生成或付费授权。
